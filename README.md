# Game Developer Portfolio

A simple, clean portfolio for game developers. Built with HTML, CSS, and JavaScript - ready for GitHub Pages.

## Features

- Clean, minimal design
- Fully responsive
- Fast loading (no build process)
- Easy to customize
- Contact form

## Sections

- **Home**: Introduction with call-to-action buttons
- **About**: About me and skills
- **Projects**: Showcase of your games
- **Contact**: Contact form and social links

## Customization

### Personal Information

Edit `index.html` to update:
- Your name and tagline (line 28-29)
- About section text (line 44-47)
- Skills (line 52-63)
- Project details (line 75-117)
- Contact information (line 130-138)

### Styling

Edit `styles.css` to customize colors:
- Primary color (line 6)
- Text colors (lines 7-8)
- Background colors (lines 9-10)

## Deployment

### GitHub Pages

1. Push this repository to GitHub
2. Go to repository Settings → Pages
3. Select the main branch as source
4. Your site will be available at `https://yourusername.github.io/repository-name`
